# Releases

One folder per version with the app and its SHA-256: a disk image (`G-Player-<version>.dmg`, from 0.4.2; open it
and drag G-Player onto Applications), or a zip for the versions before. The same files are attached to the
[GitHub release](https://github.com/RiperYT/g-player/releases) of that version.

Check a download:

```bash
shasum -a 256 -c SHA256SUMS
```
